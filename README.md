## Quick Start (Legacy Reference)

A neurodivergent-friendly logger for Rollercoaster.dev projects.

```typescript
import { Logger } from '@rollercoaster-dev/rd-logger';

const logger = new Logger({
  level: 'debug',
  serviceName: 'my-app'
});

logger.info('Application starting...');
```
